# KeyMouse Replayer

Windows 键鼠录制回放工具。全局快捷键录制键鼠操作，存成脚本文件，可调倍速回放；
回放中可暂停/继续，并支持从已执行到的位置接着跑。

- 版本：0.1.0-beta
- 平台：Windows 10 / 11（64 位）
- 定位：通用键鼠宏录制回放，不针对任何具体程序

---

## 快速开始

1. 运行 `dist\KeyMouseReplayer.exe`（或开发模式下 `python main.py`）。
2. 切到目标程序，按 `F9` 开始录制，再按 `F9` 结束录制。
3. 回到程序界面的「脚本与回放」页，点「播放」或直接按 `F10`。
4. 需要长期保存时点「保存为文件…」，得到 `.kms` 脚本文件。

### 默认快捷键

| 快捷键 | 作用 |
| --- | --- |
| `F9` | 开始 / 结束录制 |
| `F10` | 播放（已在播放则暂停/继续） |
| `F11` | 暂停 / 继续 |
| `F12` | 停止回放 |

全部可在「设置」页改成 `F6`~`F12`、`Insert`、`Home` 等，并可选配 `Ctrl` / `Alt` / `Shift`。
快捷键冲突时程序会拒绝应用并提示。

## 典型用法：一次录制、多处复用

1. 在环境 A 完整录一遍操作，保存为脚本文件（例如 `日常流程.kms`）。
2. 切到环境 B，把场景调到与录制时一致，打开同一个脚本文件点播放。
3. 如果 B 的流程比 A 长或短，用「起始位置」或回放中暂停后「从已执行位置继续」来接管。

脚本文件不绑定机器，只记录键鼠事件与相对时间，换电脑用同一个 exe + 同一个脚本即可复现。

## 回放中的干预

| 情况 | 操作 |
| --- | --- |
| 目标程序卡顿、需要手动处理 | 按 `F11` 暂停，处理完再按 `F11` 继续 |
| 想彻底中止 | 按 `F12` 停止 |
| 中途出过问题，想从某处接着跑 | 暂停或停止后点「从已执行位置继续」 |
| 想从头重放 | 点「播放」，或把「起始位置」清成 0 |

暂停时程序会**主动抬起所有按下的键盘键和鼠标键**，继续时再重新按下。
这样暂停期间不会出现「按键卡死」或「按住左键拖着鼠标」的情况。

## 倍速

「延迟倍速」在 0.1x ~ 8x 之间无级调节，也可用 0.25/0.5/1/1.5/2/3/5 的预设按钮。

- `1.0x` = 原始速度
- `2.0x` = 两倍速（时间间隔减半）
- `0.5x` = 半速（放慢一倍）

倍速只改变事件之间的等待时间，不改变事件内容与顺序。
时间轴按绝对时刻推进，因此单条事件迟到不会累积成漂移。
倍速可在**回放中实时调整**：还没等完的剩余等待按新旧倍速等比换算，
长停顿中调倍速也会立即生效。

## 脚本文件格式（.kms）

紧凑二进制格式，带版本号，可选 zlib 压缩。

```
偏移  类型   内容
0     char4  magic "KMS1"
4     u16    格式版本
6     u16    头标志（bit0 = zlib 压缩）
8     u32    事件条数
12    i32    录制时虚拟桌面 left
16    i32    录制时虚拟桌面 top
20    i32    录制时虚拟桌面 width
24    i32    录制时虚拟桌面 height
28    u32    解压后负载字节数
32    u32    文件中负载字节数
36    u32    保留
40    ...    负载
```

负载为 N 条定长 24 字节记录（小端）：

| 字段 | 含义 |
| --- | --- |
| `kind` | 事件类型：0 键按下、1 键抬起、2 鼠标移动、3 鼠标按下、4 鼠标抬起、5 滚轮、6 横向滚轮 |
| `a` | 按键=虚拟键码；鼠标键=按钮号(0左/1右/2中/3侧1/4侧2)；滚轮=增量(±120 的倍数)；移动=X 坐标 |
| `b` | 按键=扫描码；鼠标键/滚轮=X 坐标；移动=Y 坐标 |
| `c` | 按键=扩展键标志(0/1)；鼠标键/滚轮=Y 坐标；移动=0 |
| `dt_us` | 距上一条事件的微秒数（i32，上限约 35.8 分钟，录制侧超 30 分钟按 30 分钟记） |
| `flags` | 预留 |

坐标全部按**物理像素**记录。程序声明 DPI 感知，因此取到的坐标就是真实像素，
不会被系统按缩放比例换算过；前提是录制与回放两端缩放比例一致。

## 显示环境要求

回放前程序会比对当前虚拟桌面尺寸与脚本记录的值，不一致会明确提示并让你选择是否继续。

要求一致的是：

- 分辨率
- 系统缩放比例
- 多显示器布局（含主屏位置、显示器相对位置）

原因是点击坐标是绝对像素值，环境变了就会点偏。程序不代为换算——换算无法覆盖
窗口位置、UI 布局、画面比例等真正决定坐标的因素，静默换算反而会掩盖问题。

## 权限

如果目标程序以管理员身份运行，本程序也必须以管理员身份运行，否则：

- 收不到目标程序的键鼠事件（录不到）
- 无法把操作注入给目标程序（回放无效）

**启动时会自动提权。** 双击 exe 后如果当前不是管理员，程序会在创建任何窗口之前
就用系统 `runas` 重新拉起自己，旧进程立即退出。所以：

> 你看到的是系统的 UAC 确认框 → 点「是」→ 出现的第一个界面就已经是管理员权限。

中间不会先闪一个普通权限窗口，也不会出现两个窗口。

如果 UAC 里点了「否」，程序仍会以普通权限正常启动（功能受限），
侧栏与「设置 → 运行权限」会显示当前状态，并提供一个「以管理员身份重新启动」按钮。
若目标程序本身不需要管理员权限，普通权限下也能正常用。

想连 UAC 那一次点击都省掉，可以右键 exe →「属性」→「兼容性」→
勾选「以管理员身份运行」，由系统在启动时直接提权（程序检测到已是管理员后会跳过自查）。

## 性能与资源占用

| 指标 | 实测 |
| --- | --- |
| 空闲 CPU | 约 0%（消息循环阻塞等待，无轮询） |
| 空闲内存 | 约 30~40 MB（含 Tk 与界面） |
| 录制开销（上限，自旋收口） | 约 1.4% CPU，事件<1ms |
| 事件内存占用 | 24 字节/条（10 万条约 2.3 MB） |
| 单条落点精度 | 中位 0.16ms，P99 0.5ms（4000 条 × 4ms 实测） |
| 时间轴漂移 | 零累积漂移（按绝对时刻推进） |
| 10 万条存盘 / 读取 | 约 10ms / 2.5ms |
| 50 万条存盘 / 读取 | 约 46ms / 16ms |

关键设计：

- **事件不建对象**：直接写入 `array('i')`，每条 6 个 int32；块式追加，不整表复制。
- **录制零 IO**：录制期间不落盘、不格式化、不打日志。
- **键盘钩子常驻、鼠标钩子按需**：空闲时不挂鼠标钩子，减少系统开销。
- **高精度可等待定时器 + 可打断等待**：所有间隔（含几分钟的长停顿）都挂在
  定时器上，等待期间线程真正挂起，只在最后 0.2ms 自旋收口；暂停/停止事件与
  定时器一起 `WaitForMultipleObjects`，脚本长停顿中按 F11/F12 也能即时生效。
  `timeBeginPeriod` 只在拿不到高精度定时器时才作为兜底启用。
- **进度上报节流到 20Hz**：回放线程不做任何 UI 操作，UI 更新只在主线程队列泵里进行。
- **界面不随事件量增长**：预览只渲染前 300 条。

## 鼠标移动采样

录制时按阈值丢弃过密的移动点，这是控制事件量的主要手段：「设置」页可调。

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 最小间隔 | 8 ms | 间隔内的移动点丢弃 |
| 最小距离 | 2 px | 位移不足的移动点丢弃 |

调小更还原、事件更多；调大更省资源、轨迹更粗。推荐 6~10ms / 2px。
按键与点击**从不采样**，永远全量记录，保证点击时序精确。

## 从源码运行

```powershell
pip install -r requirements.txt
python main.py
```

依赖：Python 3.10+、`customtkinter`。其余（ctypes/Win32）均为标准库。
不依赖 `pywin32`、`pynput`、`keyboard` 等第三方库。
构建 exe 另需 `pip install -r requirements-dev.txt`（PyInstaller、Pillow）。

## 构建 exe

```powershell
.\tools\build.ps1              # 编译 + 自检
.\tools\build.ps1 -SkipCheck   # 只编译
```

产物：`dist\KeyMouseReplayer.exe`，单文件，无需安装 Python。

## 自检

程序内置自检，用于确认产物完整（打包后最易出问题的地方）：

```powershell
python main.py --check
dist\KeyMouseReplayer.exe --check --out result.json
```

覆盖 11 项：模块导入、CustomTkinter 资源、Tk 窗口渲染、全局钩子安装、脚本序列化往返、
坐标换算、回放时间轴精度、主界面构建、主题化对话框、提权检查接口、自带资源。

开发期另有更细的测试：

```powershell
python selftest.py all        # 核心：序列化 / 统计 / 时间轴 / 坐标 / 钩子 / 滚轮
python uitest.py              # 界面集成：录制→存盘→读盘→回放 全流程
python selftest_boot.py       # 启动流程：确认提权早于任何窗口创建
python selftest_elevation.py  # 提权逻辑：各分支与防无限重启
```

自检与测试都是无人值守的：主题化对话框会自动切到抑制模式，
不会因为有模态框而卡住（`KMR_NO_DIALOG=1` 可手动开启同样效果）。

## 已知限制

- 只支持 Windows。
- 回放不还原窗口焦点变化与前台窗口切换：脚本不记录目标窗口，注入的是全局输入。
  因此回放前需自行确保目标程序在前台。
- 不比对录制与回放时的显示器缩放比例差异，只比对虚拟桌面尺寸。
- 事件总量保护上限 1600 万条（约 384 MB 内存，保存时瞬时峰值约为 2 倍），超出后停止记录并提示。
- 单条间隔以 32 位微秒存储：录制中超过 30 分钟的停顿按 30 分钟记录（防溢出截断）。
- 不支持手柄、触屏、IME 组合输入（只记录虚拟键码层面的按键）。
